Roles de HTML, CSS y JS en el sitio
HTML: Cumple con el rol de estructurar toda la maqueta del sitio, indicando la forma en la que se organiza la base del código y el contenido en general.
CSS: Es el encargado de acomodar, dar vida y materializar los estilos, colores, formas y tamaños para que las proporciones cumplan con el estandar de un diseño adecuado para la vista.
JS: Si la página require funciones específicas, animaciones o herramientas especializadas, la lógica de JavaScript sería necesaria en este caso.

Decisiones de controles del formulario de reservas
- Correo electrónico usa input type="email" para validar el formato de correo en el navegador y facilitar su captura en móviles.
- Tipo de bicicleta usa botones radio porque se puede elegir solo una de las tres opciones.
- Fecha del alquiler usa input type="date" para capturar una fecha en un formato normalizado mediante un selector de calendario.
